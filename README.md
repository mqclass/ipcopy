## 📖 О проекте

**IP Copy** — это высокоскоростной клиентский инструмент, созданный специально для модераторов серверов Minecraft. Мод разработан в едином гармоничном визуальном стиле с интерфейсом **SpaceModeration**. 

Он в реальном времени анализирует поступающие в чат сообщения (ответы `/auth player <ник> info`, вердикты античитов, логи заходов, системные оповещения), автоматически валидирует IPv4-адреса и добавляет интерактивные кликабельные кнопки **`[Скоп. IP]`** и **`[DupeIP]`**.

В обновлении **v1.3.0** мод трансформировался в полноценный модераторский комплекс:
- ⚡ **Мгновенный вызов дашборда по клавише <kbd>I</kbd>**
- 📑 **Интерактивный 3-вкладочный интерфейс с историей сессии**
- 🧠 **Умный битовый детектор подсетей `/24` (`Subnet Matcher`) на O(1)**
- 🍞 **Нативные всплывающие System Toasts Minecraft**
- 🛡️ **Абсолютная приватность и нулевая нагрузка на процессор**

## 🚀 Ключевые возможности

### ⚡ Быстрый доступ в 1 клик
- Нажмите клавишу <kbd>I</kbd> в любой момент игры — дашборд откроется моментально.
- Бинд зарегистрирован в стандартном меню управления Minecraft (раздел `ipcopy`) и может быть переназначен на любую клавишу или кнопку мыши.
- Интеллектуальная защита: клавиша безопасно игнорируется при открытом чате, вводе команд, взаимодействии с табличками или нахождении в других GUI.

### 💬 Гармоничная интеграция в чат со SpaceModeration
- Кнопка **`[Скоп. IP]`** оформлена в стилистике кнопок SpaceModeration (`[Коп. ник]`, `[Следить]`, `[Забанить]`): благородный золотой цвет, подчеркивание при наведении и наглядная подсказка.
- При клике адрес мгновенно отправляется в буфер обмена операционной системы.
- Опциональная кнопка **`[DupeIP]`** цвета морской волны для запуска проверки твинков в один клик.

### 🔊 Тройной тактильный отклик
Каждое успешное копирование сопровождается трехуровневым подтверждением:
1. **Звук**: мягкий щелчок интерфейса Minecraft.
2. **Actionbar**: аккуратное зеленое подтверждение прямо над хотбаром.
3. **Minecraft System Toast**: стильная карточка уведомления в правом верхнем углу экрана с золотой рамкой и таймером затухания.

## 🖥 Архитектура дашборда

Дашборд открывается по нажатию клавиши <kbd>I</kbd>, по команде `.ipcopy gui` или через меню модов **ModMenu**. Интерфейс объединяет три мощных инструмента:

### 1. Вкладка `[ 🔍 Поиск по нику ]`
*Мгновенный запрос и детальный анализ истории входов любого игрока через серверную команду `/auth player <ник> info`.*

| Время сессии | IPv4 адрес | Подсеть | Интерактивные действия |
| :--- | :--- | :---: | :--- |
| `11-09-2026 23:08` | `178.62.204.18` | `⚡/24` | `[Скоп. IP]` `[DupeIP]` |
| `05-09-2026 21:45` | `94.25.180.12` | `session` | `[Скоп. IP]` `[DupeIP]` |
| `02-09-2026 23:02` | `185.230.240.209` | `session` | `[Скоп. IP]` `[DupeIP]` |

- **Интеллектуальный ввод**: мгновенная валидация никнейма (A-Z, 0-9, _) и запуск поиска по нажатию <kbd>Enter</kbd>.
- **Индикатор ожидания**: кнопка поиска анимируется в `⏳ Поиск...` с надежной защитой по таймауту.
- **Пакетный экспорт**: кнопка **`[ 📋 Все IP (N) ]`** объединяет все уникальные адреса игрока через пробел.
- **Удобная пагинация**: быстрые переключатели `◀` и `▶` (по 5 записей на страницу).

---

### 2. Вкладка `[ 📋 История (N) ]`
*Оперативный журнал адресов, с которыми работал модератор во время текущей сессии.*

| Таймстемп | Скопированный IP | Подсеть /24 | Доступные действия |
| :---: | :--- | :---: | :--- |
| `[14:22:05]` | `178.62.204.18` | `178.62.204.0/24` | `[Скоп. IP]` `[🔍 В поиск]` `[DupeIP]` |
| `[14:21:50]` | `94.25.180.12` | `94.25.180.0/24` | `[Скоп. IP]` `[🔍 В поиск]` `[DupeIP]` |
| `[14:20:12]` | `185.230.240.209` | `185.230.240.0/24` | `[Скоп. IP]` `[🔍 В поиск]` `[DupeIP]` |

- **Точные таймстемпы**: фиксация момента копирования в формате `[HH:mm:ss]`.
- **Быстрый переход `[🔍 В поиск]`**: перенос выбранного адреса в поисковую строку дашборда в 1 клик.
- **Массовая выгрузка `[ 📋 Все (N) ]`**: копирование всей накопленной истории сессии в системный буфер.
- **Очистка памяти `[ 🗑 Очистить ]`**: моментальное обнуление оперативного журнала в RAM.

---

### 3. Вкладка `[ ⚙ Настройки ]`
*Компактный двухколоночный центр управления всеми модулями мода с сохранением в реальном времени.*

| Левая колонка (Интерфейс и отклик) | Правая колонка (Логика и утилиты) |
| :--- | :--- |
| 🔘 **`[ Мод: ВКЛ / ВЫКЛ ]`**<br>_Глобальный переключатель работы мода_ | 🔘 **`[ Подсети /24: ВКЛ / ВЫКЛ ]`**<br>_Автоматическое выделение общих подсетей_ |
| 🔘 **`[ Звук клика: ВКЛ / ВЫКЛ ]`**<br>_Акустический щелчок при копировании_ | 🔘 **`[ История RAM: ВКЛ / ВЫКЛ ]`**<br>_Ведение сессионного журнала в памяти_ |
| 🔘 **`[ Actionbar: ВКЛ / ВЫКЛ ]`**<br>_Индикатор подтверждения над хотбаром_ | 🔘 **`[ /dupeip: ВКЛ / ВЫКЛ ]`**<br>_Вторая кнопка быстрых действий в чате_ |
| 🔘 **`[ Toast: ВКЛ / ВЫКЛ ]`**<br>_Всплывающее уведомление Minecraft_ | ⚡ **`[ Отправить тест ]`**<br>_Генерация демонстрационного сообщения_ |

## ⚡ Умный детектор подсетей /24 (Subnet Matcher)

Модераторы регулярно сталкиваются с игроками, использующими динамические IP-адреса или мобильный интернет одного провайдера. **Subnet Matcher** мгновенно определяет, принадлежат ли разные IP одной и той же подсети класса `/24` (первые 3 октета, например `178.62.204.0/24`).

### Технические преимущества алгоритма:
- **Побитовая арифметика $O(1)$**: каждый IP конвертируется в 32-битное целое число (`int`). Сравнение выполняется на уровне микропроцессорных инструкций через битовую маску `0xFFFFFF00`:
  ```java
  int mask24 = 0xFFFFFF00;
  boolean sameSubnet = (ipBits1 & mask24) == (ipBits2 & mask24);
  ```
- **0 байт промежуточных аллокаций**: никаких строковых манипуляций и регулярных выражений при анализе пар адресов.
- **Безопасность**: полное исключение риска уязвимостей типа ReDoS (Regular Expression Denial of Service).
- **Визуальный маркер**: сессии из совпадающих подсетей маркируются контрастным бейджем **`§d[⚡/24]`**.

## 🍞 Системные уведомления (Minecraft System Toasts)

При копировании IP в правом верхнем углу всплывает нативное уведомление Minecraft:

> **[IPCopy]** ✔ IP скопирован!  
> `178.62.204.18`

- **Стилистика**: темная карточка с золотой окантовкой, выдержанная в строгом дизайне SpaceModeration.
- **Тайминг**: плавное появление, удержание в течение **2.5 секунд** и мягкое исчезновение.
- **Надежность**: отрисовка через нативные примитивы `DrawContext`, что гарантирует безупречный вид независимо от используемых ресурспаков.

## 🔍 Алгоритм валидации IPv4

Мод использует строгий двухэтапный конвейер валидации, предотвращающий ложные срабатывания на версии игры (например `1.21.11`), координаты блоков, дробные числа или даты:

| Критерий | Требование | Назначение |
| :--- | :---: | :--- |
| **Количество точек** | Ровно **3** | Отсекает версии вроде `1.21.11` и списки параметров |
| **Количество цифр** | от **4** до **12** | Соответствует диапазону от `1.1.1.1` до `255.255.255.255` |
| **Длина строки** | от **7** до **15** символов | Стандартная длина корректной записи IPv4 |
| **Диапазон октетов** | от **0** до **255** | Каждый из 4 октетов парсится и проверяется на валидность |
| **Границы слова** | Negative lookaround | Исключает захват чисел внутри хэшей или длинных строк |

## 🤝 Интеграция со SpaceModeration

Мод разработан с глубоким уважением к экосистеме **SpaceModeration**:
- **Умный перехват команд**: команды `.ipcopy` и `.apf` обрабатываются локально до того, как они попадут в чат сервера или вызовут ошибку неизвестной команды.
- **Встраивание в `.help`**: модуль справки SpaceModeration автоматически расширяется блоком документации IP Copy.
- **Автодополнение**: аргументы и подкоманды `.ipcopy` регистрируются в автокомплите чата.
- **Визуальная синергия**: типографика, цвета (`§6 Gold`, `§b Aqua`), форматирование ховеров и кнопок создают ощущение единого монолитного интерфейса.

## 🔒 Приватность и безопасность

- 🚫 **0 внешних HTTP/HTTPS запросов**: мод не выполняет сетевых запросов во внешнюю сеть, не собирает аналитику и не передает данные третьим лицам.
- 🧠 **Хранение строго в оперативной памяти (RAM)**: история сессий и скопированные адреса не сохраняются на жесткий диск.
- 🧹 **Автоматическое уничтожение данных**: при отключении от сервера или смене мира память журнала и кэш сессий немедленно очищаются.
- 🛡️ **Изолированные миксины**: все внедрения в код игры имеют флаг `require = 0`, исключая конфликты с другими модами.

## 📥 Инструкция по установке

1. Убедитесь, что у вас установлен **Fabric Loader** для Minecraft **1.21.11** и библиотека **Fabric API**.
2. Скачайте файл **`ipcopy-1.3.0.jar`** из раздела [Releases](https://github.com/mqclass/ipcopy/releases).
3. Поместите `.jar` файл в папку `mods` вашего клиента:
   - **Обычный лаунчер**: `%appdata%\.minecraft\mods\`
   - **FreesmLauncher**: `%appdata%\FreesmLauncher\instances\<имя_сборки>\minecraft\mods\`
4. Запустите игру.
5. Нажмите клавишу <kbd>I</kbd> для мгновенного входа в дашборд!

## 🔨 Инструкция по сборке

### Вариант 1: Сборка через Gradle Wrapper
В корневой директории проекта выполните команду:
```bash
./gradlew jar
```
Готовый файл мода будет скомпилирован по пути:
```
build/libs/ipcopy-1.3.0.jar
```

### Вариант 2: Сборка через PowerShell
Для мгновенной компиляции без загрузки лишних зависимостей воспользуйтесь встроенным скриптом `build.ps1`:
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
Скрипт собирает проект через UTF-8 argument file, компонует итоговый `.jar` и автоматически копирует его в директорию модов сборки.
