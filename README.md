## О моде

**IP Copy** разработан для модераторов и персонала серверов Minecraft (в частности SpaceTimes и серверов с плагинами авторизации). Мод автоматизирует рутинные проверки игроков на мультиаккаунты (ScreenShare / PC Check), исключает механический ввод команд и обходит серверные ограничения на частоту отправки команд.

---

## Ключевые возможности v1.5.0

### ⚡ Асинхронный пакетный сканер IP (Scan Queue Manager)
- **Умный Rate Limiter (1250ms)**: автоматическая очередь отправки команд проверки с интервалом по умолчанию 1250ms, гарантированно не триггерящая серверный anti-spam кулдаун 1200ms.
- **Запуск в один клик**:
  - Кнопка **`[⚡ Скан]`** прямо в поисковой строке дашборда для любого открытого игрока.
  - Интерактивная кнопка **`[⚡ ПРОВЕРИТЬ ВСЕ (X уник.)]`**, автоматически прикрепляемая к сообщениям чата со списками сессий (`/seen`, `/history`, `/dupeip`).
  - Команда в чате: `.ipcopy scan <ник или список IP>`.
- **Управление очередью**: возможность ставить сканирование на паузу (`.ipcopy pause`), возобновлять (`.ipcopy resume`) или прерывать (`.ipcopy cancel`).

### 🛡 Подавление спама ответов в чате (Chat Suppression)
- Во время активного авто-сканирования десятки входящих строк ответов сервера на `/dupeip` или `/check` автоматически скрываются из чата игрока (`ci.cancel()`) и агрегируются в единый отчет сессии.

### 💾 Локальный кэш проверенных IP (30-Min LRU Cache)
- Если IP-адрес уже проверялся в течение последних 30 минут, повторный сетевой запрос не отправляется — результат мгновенно берется из оперативной памяти.

### 🖥 Наэкранный HUD-оверлей прогресса (Scan HUD Overlay)
- Элегантная темная полупрозрачная карточка в правом верхнем углу экрана во время сканирования:
  - Целевой никнейм игрока;
  - Прогресс: `X / Y [Z%]`;
  - Текущий проверяемый IP и расчётное время до завершения (`ETA: Xs`);
  - Плавная полоса прогресса (Progress Bar);
  - Баннер завершения с плавным скрытием (Fadeout 3.5 сек).

### 🔔 Завершение и интерактивный отчет
- По окончании проверки воспроизводится звуковой сигнал колокольчика `block.note_block.bell`.
- В чат выводится компактное итоговое сообщение с кнопками:
  - **`[📋 СКОПИРОВАТЬ ОТЧЕТ]`** — форматированный отчет с детализацией по каждому IP и твинку для быстрой вставки в Discord/тикет.
  - **`[🔍 В GUI]`** — переход в дашборд игрока.

### 🚶‍♂️ Защита от AFK-кика (Anti-AFK KeepAlive)
- Предотвращает кик модератора за «Вы слишком долго бездействовали» во время длительных проверок или нахождения в GUI через периодическую отправку легкого пакета взмаха руки (`swing hand`) и микро-доворота камеры каждые 42–55 секунд.

### 🎨 Pixel-Perfect Дашборд
- **Устранение просвечивания мира**: глубокое затемнение игрового мира и темный контейнер карточки полностью блокируют никнеймы игроков над головами и элементы интерфейса.
- **Динамический размер таблицы**: фон таблицы адаптируется под реальное число строк (никаких пустых черных дыр при 1–3 строках).
- **Идеальное позиционирование**: заголовок, профиль, быстрые действия и строки таблицы согласованы по вертикали и не перекрывают друг друга.
- **Безупречный Ctrl+V**: вставка никнейма из буфера обмена работает в любой момент при открытом дашборде, даже если текстовое поле не было предварительно сфокусировано кликом.

## Управление и команды

| Клавиша / Команда | Описание |
| :--- | :--- |
| <kbd>I</kbd> | Открыть дашборд мода |
| `.ipcopy` | Справка по моду в чате |
| `.ipcopy gui [ник]` | Открыть меню мода (если указан ник — сразу ищет его) |
| `.ipcopy scan <ips\|ник>` | Запустить авто-сканирование IP с защитой от кулдауна |
| `.ipcopy pause` | Поставить текущее сканирование на паузу |
| `.ipcopy resume` | Возобновить сканирование с места остановки |
| `.ipcopy cancel` | Прервать текущую очередь сканирования |
| `.ipcopy test` | Отправить тестовое сообщение с IP для проверки кнопок |
| `.ipcopy toggle` | Быстро включить или выключить мод |
| `.ipcopy history` | Показать последние скопированные IP в чате |
| `.ipcopy clear` | Очистить историю скопированных IP в памяти |
| `.ipcopy reload` | Перезагрузить конфиг из файла |
| `.apf <ник>` | Быстрый поиск сессий указанного игрока |

Все команды также поддерживают стандартный префикс со слэшем (`/ipcopy`, `/apf`).

## Настройки (`config/ipcopy.json`)

Параметры можно менять в игре (вкладка «Настройки» в меню или через ModMenu), либо в файле `config/ipcopy.json`:

| Параметр | По умолчанию | Описание |
| :--- | :---: | :--- |
| `enabled` | `true` | Включение / выключение мода |
| `scanDelayMs` | `1250` | Задержка между командами авто-сканирования (мс) для обхода кулдауна 1200мс |
| `showHudOverlay` | `true` | Отображение наэкранного HUD-оверлея прогресса проверки |
| `antiAfk` | `true` | Защита от кика за бездействие (Anti-AFK KeepAlive) во время проверок |
| `autoScanButtonInChat` | `true` | Интерактивная кнопка `[⚡ ПРОВЕРИТЬ ВСЕ]` в сообщениях со списками сессий |
| `soundFeedback` | `true` | Звуковой отклик клика и завершения проверки |
| `actionbarFeedback` | `true` | Уведомление над хотбаром при копировании |
| `toastFeedback` | `true` | Всплывающий системный тост Minecraft в углу экрана |
| `silentChatMode` | `false` | Скрытый режим чата (ответы /auth и /dupeip обрабатываются фоново) |
| `autoFetchAllPages` | `false` | Автоматически собирать все страницы при поиске игрока |
| `preferUniqueIpsView` | `true` | Показывать сгруппированные уникальные IP по умолчанию |
| `highlightSubnets` | `true` | Подсветка одинаковых подсетей `/24` меткой `[⚡/24]` |
| `sessionHistory` | `true` | Ведение журнала истории копирований в памяти RAM |
| `showSecondAction` | `false` | Отображение второй кнопки (`[DupeIP]`) рядом с кнопкой копирования |
| `secondActionCommand` | `"/dupeip %ip%"` | Шаблон команды проверки твинков |
| `showQuickActions` | `true` | Панель быстрых модераторских действий в профиле игрока |

## Установка

1. Установите **Fabric Loader** (1.21.11) и **Fabric API**.
2. Скачайте файл **`ipcopy-1.5.0.jar`** со страницы [Releases](https://github.com/mqclass/ipcopy/releases).
3. Поместите `.jar` в папку `.minecraft/mods/`.
4. (Опционально) Установите **SpaceModeration** и **ModMenu**.

---

## Сборка из исходников

Для сборки требуется **Java 21**:

```bash
git clone https://github.com/mqclass/ipcopy.git
cd ipcopy
./gradlew jar
```

Готовый файл мода появится в папке `build/libs/`.
