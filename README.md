# 🌐 IP Copy by mqclass (Fabric 1.21.11)

> **IP Copy** — флагманский клиентский Fabric-мод для Minecraft 1.21.11, созданный специально для максимально удобной, быстрой и профессиональной модерации серверов. Мод вдохновлен интерфейсом **SpaceModeration** и автоматически находит IPv4-адреса (в чате, в ответе `/auth player <ник> info`, в логах античитов), добавляя интерактивные кнопки **`[Скоп. IP]`** и **`[DupeIP]`**.
> 
> В версии **1.3.0** мод получил грандиозное расширение: нативную горячую клавишу **`[I]`**, полноценный 3-вкладочный дашборд с вкладкой **`[📋 История]`**, умный битовый детектор подсетей **`/24`** (`Subnet Matcher`) и системные уведомления Minecraft **System Toasts**.

**Автор мода:** `mqclass`  
**Платформа:** Fabric 1.21.11 (Java 21)  
**Лицензия:** MIT

## 🚀 Главные возможности

- **Мгновенный доступ по клавише `[I]`**: Нажмите клавишу `I` в игре — панель модератора мгновенно откроется поверх экрана. Клавишу можно переназначить в стандартном меню управления Minecraft.
- **Автоматический захват IP в чате**: Сканирует входящие сообщения (алерты SAC, ответы плагинов `/auth`, `/check`, `/whois`, `/dupeip`, `/alts`, логи заходов игроков, консольные сообщения и личные сообщения).
- **Копирование в 1 клик**: При клике на `[Скоп. IP]` адрес моментально копируется в системный буфер обмена вашей ОС (Windows).
- **Стиль SpaceModeration**: Оформление кнопки выполнено в стилистике `[Коп. ник]` из SpaceModeration — благородный золотой цвет (`§6`), автоподчеркивание при наведении и подсказка.
- **Тройной тактильный отклик**: Звук щелчка, зеленое подтверждение в Actionbar над хотбаром и всплывающий нативный System Toast в правом верхнем углу!
- **3-вкладочный дашборд**:
  - `[ 🔍 Поиск по нику ]` — запрос истории входов игрока через `/auth player <ник> info`, таблица сессий с пагинацией и кнопкой копирования всех адресов.
  - `[ 📋 История (N) ]` — таблица последних скопированных IP с точным временем `[HH:mm:ss]`, бейджем `/24`, кнопками быстрого повторного копирования и проверки твинков.
  - `[ ⚙ Настройки ]` — удобная панель переключателей в 2 колонки.
- **Умный детектор подсетей `/24`**: Автоматически находит совпадения первых 3 октетов (например, `178.62.204.x`) и подсвечивает бейджем `§d[⚡/24]`.
- **Безопасная сессионная память**: История скопированных адресов хранится исключительно в RAM и автоматически уничтожается при выходе с сервера.

## ⚡ Умный детектор подсетей /24 (Subnet Matcher)

Модераторам часто необходимо понимать, заходит ли игрок с разных IP одного и того же интернет-провайдера (динамический IP, перезагрузка роутера, мобильный интернет).
- Мод группирует IP-адреса по маске `/24` (первые 3 октета, например `178.62.204.0/24`).
- Если у игрока обнаружено несколько заходов с одной подсети, строка выделяется бейджем **`§d[⚡/24]`**.
- Алгоритм работает на 32-битных целочисленных битовых масках: **O(1)** скорость, **0 байт** промежуточных аллокаций, **0% риска ReDoS**.

## 🍞 Системные тосты (Minecraft Toasts)

При копировании IP в правом верхнем углу всплывает нативное окно Minecraft `IpToast`:
- **Заголовок:** `§6[IPCopy] §a✔ IP скопирован!`
- **Подзаголовок:** `§e178.62.204.18`
- **Продолжительность:** 2.5 секунды.
- Потокобезопасная отправка через `Render thread`.
- Рендеринг через примитивы контекста, гарантирующий 100% совместимость с любыми ресурспаками.

## 🔍 Алгоритм и критерии распознавания IP

| Параметр | Требование | Пояснение |
| :--- | :--- | :--- |
| **Количество цифр (без точек)** | от **4** до **12** | `1.1.1.1` (4 цифры) ... `255.255.255.255` (12 цифр) |
| **Всего символов (с 3 точками)** | от **7** до **15** | `1.1.1.1` (7 символов) ... `255.255.255.255` (15 символов) |
| **Октеты** | Ровно 4 числа | Каждое число разделено точкой и лежит в пределах `0..255` |
| **Количество точек** | Ровно **3** | Исключает версии игры (например `1.21.11`), координаты и дроби |

## 🤝 Интеграция со SpaceModeration

- Полная совместимость со **SpaceModeration 3.5.1**.
- `.ipcopy` и `.apf` перехватываются до SpaceModeration и не спамят в чат сервера.
- В справку `.help` SpaceModeration автоматически добавляется справочный блок IP Copy.
- Автокомплит SpaceModeration дополняется командами мода.
- Кнопка `[Скоп. IP]` гармонично встает в ряд с `[Коп. ник]`, `[Следить]`, `[Забанить]`.

## 🔒 Приватность и безопасность

- **0 внешних сетевых запросов**: Мод не выполняет HTTP/HTTPS запросов, не отправляет телеметрию и не собирает данные.
- **Хранение только в RAM**: Все данные сессий и скопированные IP живут только в оперативной памяти и очищаются при отключении от сервера.
- **Никаких изменений чужих JAR**: Чистая интеграция через безопасные миксины с `require = 0`.

## 📥 Инструкция по установке

1. Убедитесь, что у вас установлен **Fabric Loader** для Minecraft **1.21.11** и **Fabric API**.
2. Поместите файл **`ipcopy-1.3.0.jar`** в папку `mods` вашего инстанса Minecraft:
   ```text
   .minecraft/mods/
   ```
   *(В FreesmLauncher: `FreesmLauncher/instances/<имя_сборки>/minecraft/mods/`)*
3. Запустите Minecraft.
4. Нажмите клавишу **`I`** для мгновенного вызова дашборда или введите `.ipcopy gui` в чате!

## 🔨 Инструкция по сборке

### Вариант 1: Через Gradle Wrapper
```bash
.\gradlew.bat jar
```
Файл будет создан в `build/libs/ipcopy-1.3.0.jar`.

### Вариант 2: Через PowerShell-скрипт
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
Скрипт компилирует проект через argument file, упаковывает `ipcopy-1.3.0.jar` и автоматически копирует его в вашу сборку `1.21.11 SM` FreesmLauncher.
