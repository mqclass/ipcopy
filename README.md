## О моде

**IP Copy** находит IPv4-адреса во входящих сообщениях чата (логи заходов, алерты, системные сообщения) и прикрепляет к ним кликабельную кнопку **`[Скоп. IP]`**. Дизайн кнопок гармонично сочетается со стилем **SpaceModeration**.

При клике адрес сразу копируется в буфер обмена, проигрывается негромкий звук клика и показывается уведомление (в экшнбаре или в виде системного тоста).

По нажатию клавиши <kbd>I</kbd> открывается многофункциональный интерфейс мода с полной автоматизацией проверки игроков, авто-сбором истории, проверкой твинков и экспресс-досье.

## Возможности v1.5.0

- **⚡ Авто-сбор страниц сессий (Auto-Crawler)**: кнопка `[⚡ Собрать всё]` автоматически собирает все 10–40 страниц сессий игрока с безопасным интервалом 1.35с (без киков за спам команд) и живой индикацией прогресса `[⏳ X/Y]`.
- **⭐ Режим сгруппированных уникальных IP**: объединяет десятки повторяющихся сессий в компактные строки с подсчётом доли входов (`26 вх. (93%)`), подсетью `/24` и статусом твинков. Больше не нужно листать 8 страниц!
- **⚡ Пакетный чекер твинков (Batch DupeIP)**: кнопка `[⚡ DupeIP]` по очереди отправляет `/dupeip` для каждого уникального IP, перехватывает ответ сервера и подсвечивает бейджи:
  - `§c[⚠ N тв.]` — обнаружены мультиаккаунты (клик сразу копирует ники твинков в буфер обмена!);
  - `§a[✔ Чист]` — твинков не обнаружено.
- **📋 Экспресс-досье в 1 клик**: кнопка `[📋 Досье]` форматирует и копирует готовый структурированный отчёт (профиль, UUID, соцсети, уникальные IP, подсети, твинки) для мгновенной вставки в тикет или Discord.
- **🕵 Скрытый режим чата (Stealth Mode)**: ответы `/auth` и `/dupeip` обрабатываются фоново в дашборде без засорения игрового чата.
- **Кнопка `[Скоп. IP]` в чате**: копирование найденного IP в буфер обмена в один клик.
- **Вторая кнопка (опционально)**: кнопка `[DupeIP]` в чате для быстрой проверки твинков.
- **Меню по клавише <kbd>I</kbd>**: мгновенное открытие GUI мода. Клавишу можно переназначить в настройках Minecraft.
- **Вкладка «Поиск по нику»**: ввод никнейма, отображение дат и адресов входов, панель быстрых действий (`[ℹ Инфо]`, `/mute`, `/ban` и др.) и экспорт отчёта.
- **Вкладка «История»**: журнал скопированных адресов с живым поисковым фильтром.
- **Детектор подсетей /24**: адреса с одинаковыми подсетями подсвечиваются меткой `[⚡/24]`.
- **Конфиденциальность**: данные сессий хранятся исключительно в оперативной памяти и очищаются при выходе.

## Управление и команды

| Клавиша / Команда | Описание |
| :--- | :--- |
| <kbd>I</kbd> | Открыть меню мода |
| `.ipcopy` | Справка по моду в чате |
| `.ipcopy gui [ник]` | Открыть меню мода (если указан ник — сразу ищет его) |
| `.ipcopy test` | Отправить тестовое сообщение с IP для проверки кнопок |
| `.ipcopy toggle` | Быстро включить или выключить мод |
| `.ipcopy history` | Показать последние скопированные IP в чате |
| `.ipcopy clear` | Очистить историю скопированных IP в памяти |
| `.ipcopy reload` | Перезагрузить конфиг из файла |
| `.apf <ник>` | Быстрый поиск сессий указанного игрока |

Все команды также работают через слэш (`/ipcopy`, `/apf`).

## Настройки (`config/ipcopy.json`)

Параметры можно менять прямо в меню игры (вкладка «Настройки» или через ModMenu), либо в файле `config/ipcopy.json`:

| Параметр | По умолчанию | Описание |
| :--- | :---: | :--- |
| `enabled` | `true` | Включение / выключение мода |
| `soundFeedback` | `true` | Звук щелчка при клике на кнопку |
| `actionbarFeedback` | `true` | Зеленое сообщение над хотбаром |
| `toastFeedback` | `true` | Всплывающий системный тост в углу экрана |
| `silentChatMode` | `false` | Скрытый режим чата (ответы /auth и /dupeip не спамят в чат) |
| `autoFetchAllPages` | `false` | Автоматически собирать все страницы при поиске игрока |
| `preferUniqueIpsView` | `true` | Показывать сгруппированные уникальные IP по умолчанию |
| `highlightSubnets` | `true` | Подсветка одинаковых подсетей `/24` меткой `[⚡/24]` |
| `sessionHistory` | `true` | Ведение журнала истории копирований в памяти |
| `showSecondAction` | `false` | Отображение второй кнопки (`[DupeIP]`) рядом с кнопкой копирования |
| `secondActionCommand` | `"/dupeip %ip%"` | Команда для второй кнопки (`%ip%` заменяется на адрес) |
| `showQuickActions` | `true` | Панель быстрых модераторских действий в профиле игрока |

## Установка

1. Установите **Fabric Loader** (1.21.11) и **Fabric API**.
2. Скачайте файл **`ipcopy-1.5.0.jar`** со страницы [Releases](https://github.com/mqclass/ipcopy/releases).
3. Поместите `.jar` в папку `.minecraft/mods/`.
4. (Опционально) Установите **SpaceModeration** и **ModMenu**.

---

## Сборка из исходников

Для сборки требуется **Java 21**:

```bash
git clone https://github.com/mqclass/ipcopy.git
cd ipcopy
./gradlew jar
```

Готовый файл мода появится в папке `build/libs/`.
