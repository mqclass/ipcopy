# 🌐 IP Copy by mqclass (Fabric 1.21.11)

> **IP Copy** — клиентский Fabric-мод для Minecraft 1.21.11, созданный специально для удобной и быстрой модерации серверов. Мод вдохновлен интерфейсом **SpaceModeration** и автоматически находит IPv4-адреса (в том числе в ответе `/auth player <ник> info` и алертах античитов), добавляя интерактивную кнопку **`[Скоп. IP]`** для моментального копирования адреса в буфер обмена.
> 
> В версии **1.2.0** реализован **интерактивный дашборд поиска по нику (`.ipcopy gui [ник]`)**: вводите никнейм — мод запрашивает историю входов и выводит интерактивную таблицу всех сессий, кнопку **`[📋 Скопировать все IP]`**, быстрый переход к `/dupeip`, а также нативную вкладку конфигурации и ModMenu.

**Автор мода:** `mqclass`  
**Платформа:** Fabric 1.21.11 (Java 21)  
**Лицензия:** MIT

## 🚀 Главные возможности

- **Автоматический захват IP в чате**: Сканирует все входящие сообщения (алерты античитов SAC, ответы плагинов `/auth`, `/check`, `/whois`, `/dupeip`, `/alts`, логи заходов игроков, консольные сообщения и личные сообщения).
- **Копирование в 1 клик**: При клике на `[Скоп. IP]` адрес моментально копируется в системный буфер обмена вашей ОС (Windows).
- **Стиль SpaceModeration**: Оформление кнопки выполнено в точности как `[Коп. ник]` из SpaceModeration — благородный золотой цвет (`Formatting.GOLD` / `§6`), автоподчеркивание при наведении и информативная всплывающая подсказка.
- **Тактильная обратная связь**: При копировании воспроизводится ненавязчивый щелчок интерфейса, а над панелью быстрого доступа (Actionbar) появляется стильное зеленое подтверждение: `✔ IP скопирован в буфер: 1.2.3.4`.
- **Нативный GUI и ModMenu**: Полноценный экран настроек без сторонних библиотек, открываемый через `.ipcopy gui` или шестеренку в ModMenu.
- **Безопасная история сессии**: В оперативной памяти сохраняются до 10 последних скопированных IP с возможностью повторного копирования по команде `.ipcopy history`. При выходе с сервера память автоматически очищается.
- **Опциональная вторая кнопка (`[DupeIP]`)**: Можно включить в настройках дополнительную бирюзовую кнопку для мгновенного выполнения команды проверки мультиаккаунтов (`/dupeip %ip%`).

## 🔍 Алгоритм и критерии распознавания IP

Поиск и валидация IP-адресов соответствуют строгим правилам формата IPv4:

| Параметр | Требование | Пояснение |
| :--- | :--- | :--- |
| **Количество цифр (без точек)** | от **4** до **12** | Минимальный IP: `1.1.1.1` (4 цифры), максимальный: `255.255.255.255` (12 цифр) |
| **Всего символов (с 3 точками)** | от **7** до **15** | `1.1.1.1` (7 символов) ... `255.255.255.255` (15 символов) |
| **Октеты** | Ровно 4 числа | Каждое число разделено точкой и лежит в пределах `0..255` |
| **Количество точек** | Ровно **3** | Исключает дробные числа, координаты и диапазоны |

### Регулярное выражение с Lookaround-границами:
```regex
(?<![0-9.])(?:(?:25[0-5]|2[0-4][0-9]|1[0-9]{2}|[0-9]{1,2})\.){3}(?:25[0-5]|2[0-4][0-9]|1[0-9]{2}|[0-9]{1,2})(?![0-9.])
```

### Защита от ложных срабатываний:
- **Версии игры**: Строки вида `1.21.11` или `1.20.4` содержат всего 2 точки, поэтому **никогда** не будут восприняты как IP.
- **IP с портами**: В строках вида `127.0.0.1:25565` мод аккуратно извлекает только чистый адрес `127.0.0.1`.
- **IP в скобках и со слэшами**: `[192.168.1.1]` или `/8.8.8.8` корректно распознаются без мусорных символов.
- **Невалидные числа**: Строки вроде `999.999.999.999` или слишком длинные последовательности `1.2.3.4.5` отсеиваются на этапе валидации.

## 🖱 Как работает кнопка `[Скоп. IP]`

1. **Отображение в чате**:
   - Текст кнопки: `[Скоп. IP]` (или `[Скоп. IP: 1.2.3.4]`, если в одном сообщении несколько разных IP).
   - Цвет: Золотой (`§6` / `Formatting.GOLD`).
   - Наведение курсора: Курсор меняется, текст кнопки подчеркивается, и всплывает подсказка:
     ```text
     §6[IPCopy] §eНажмите, чтобы скопировать IP:
     §a178.62.204.18
     §7Мод сделал §6mqclass
     ```
2. **Клик по кнопке**:
   - IP мгновенно копируется в системный буфер обмена Windows.
   - Воспроизводится звук щелчка кнопки интерфейса (если включен в настройках).
   - В Actionbar выводится: `✔ IP скопирован в буфер: 178.62.204.18`.
   - IP заносится в историю текущей сессии (до 10 адресов).

## 🤝 Интеграция со SpaceModeration

Мод разработан с учетом совместной работы с модом **SpaceModeration 3.5.1**:

- Для SpaceModeration 3.5.1 используется отдельная безопасная интеграция с его `DotCommandHandler`.
- `.ipcopy` и `.apf` перехватываются до SpaceModeration и не отправляются в серверный чат.
- В конец встроенной справки `.help` автоматически добавляется блок IP Copy.
- Подсказки команд (автокомплит) SpaceModeration автоматически обогащаются командами `.ipcopy gui`, `.ipcopy test`, `.ipcopy toggle`, `.ipcopy history` и `.apf <ник>`.
- Если SpaceModeration не установлен, все команды продолжают работать в штатном режиме через стандартные механизмы Fabric.
- Если в сообщении античита уже есть ряд кнопок SpaceModeration:
  ```text
  SAC > Игрок Steve подозрителен с IP: 178.62.204.18 (Буфер: 32.7)
  [Следить] [Найти] [Забанить] [Коп. ник] [Скоп. IP]
  ```
  кнопка `[Скоп. IP]` аккуратно прикрепляется в конец этого ряда.

## ⌨ Внутриигровые команды

| Команда | Описание |
| :--- | :--- |
| `.ipcopy` | Выводит справку по моду с кликабельными кнопками открытия GUI и теста. |
| `.ipcopy gui [ник]` | Открывает нативное меню мода. Если указан ник — сразу открывает дашборд с его IP. |
| `.ipcopy test` | Показывает локальный ответ игрока `DiNoKy` с тремя разными IP для проверки кнопок. |
| `.ipcopy toggle` | Быстро переключает статус мода (ВКЛЮЧЕН / ВЫКЛЮЧЕН). |
| `.ipcopy history` | Показывает историю скопированных IP в текущей сессии с кнопками быстрого перекопирования. |
| `.ipcopy clear` | Очищает историю сессии в памяти. |
| `.ipcopy reload` | Перезагружает конфигурационный файл `ipcopy.json` с диска. |
| `.apf <ник>` | Отправляет на сервер команду `/auth player <ник> info`. |

*Алиасы со слэшем (`/ipcopy gui [ник]`, `/ipcopy test`, `/ipcopy toggle`, `/ipcopy history`, `/apf <ник>`) также полностью поддерживаются.*

## 🔒 Приватность и безопасность

- **Никаких утечек**: IP Copy не выполняет внешних HTTP/HTTPS запросов, не открывает сетевые порты и не собирает телеметрию.
- **Никакой записи IP на диск**: История скопированных адресов и кэш сессий игроков хранятся **только в оперативной памяти** (в RAM) и **полностью уничтожаются** при выходе с сервера или перезапуске игры.
- **Никакого изменения чужих JAR**: SpaceModeration и другие моды не перепаковываются и не модифицируются.
- **Защита от зависаний и спама**: Обработка ограничена 32 767 символами на сообщение и максимум 64 адресами. Все ошибки парсинга компонентов изолированы безопасными блоками `try-catch`.

## 📥 Инструкция по установке

1. Убедитесь, что у вас установлен **Fabric Loader** для Minecraft **1.21.11** и **Fabric API**.
2. Поместите файл **`ipcopy-1.2.0.jar`** в папку `mods` вашего инстанса Minecraft:
   ```text
   .minecraft/mods/
   ```
   *(Если вы используете FreesmLauncher: `FreesmLauncher/instances/<имя_сборки>/minecraft/mods/`)*
3. Запустите Minecraft.
4. В игре откройте чат и напишите `.ipcopy gui` или проверьте наличие кнопки настроек у мода в ModMenu.
5. Для теста работы поиска используйте кнопку `[Тест: DiNoKy]` прямо в интерфейсе!

## 🔨 Инструкция по сборке

### Вариант 1: Через Gradle Wrapper
```bash
.\gradlew.bat jar
```
Собранный JAR-файл появится в `build/libs/ipcopy-1.2.0.jar`.

### Вариант 2: Через PowerShell-скрипт
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
Скрипт автоматически компилирует проект, упаковывает `ipcopy-1.2.0.jar` и копирует его в вашу сборку FreesmLauncher.
